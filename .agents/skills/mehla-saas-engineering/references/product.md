# نطاق منتج مِهلة

مِهلة منصة SaaS قانونية سعودية للمحامين ومكاتب المحاماة والإدارات القانونية. رسالتها: تنظيم القضايا والجلسات والمهل النظامية والمهام والمستندات والتنبيهات حتى يعرف المستخدم ما يحتاج إلى إجراء قبل فوات الوقت.

## الوحدات الأساسية

- القضايا والعملاء والجلسات والمهل والمهام والتقويم.
- المستندات وسجل إجراءات القضية والمشاركة الآمنة مع العميل.
- المستخدمون والأدوار والصلاحيات وعزل بيانات كل مكتب.
- لوحة اليوم، التنبيهات، التقارير، وسجل التدقيق.
- الاشتراكات والباقات والفواتير والمدفوعات وعروض الأسعار.
- لوحة مالك المنصة، CRM، الموارد البشرية، التسويق، الدعم والبريد.
- الصفحة العامة للمكتب والنطاقات الفرعية واستوديو المظهر.
- تكاملات البريد وWhatsApp وWebhooks والإشعارات.

## مبادئ المنتج

- مِهلة أداة تنظيم وتشغيل وليست بديلاً عن ناجز ولا تقدم استشارة قانونية.
- لا تعرض بيانات تجريبية أو أرقام نجاح وهمية في صفحات الإنتاج.
- لا تعرض ميزة خارجية على أنها عاملة قبل اختبار اتصال المزود الحقيقي.
- كل زر ظاهر يعمل أو يكون معطلاً مع سبب واضح.
- الواجهة عربية RTL، مؤسسية، هادئة، ومتجاوبة.
