# مهارة مصمم واجهات المستخدم وتجربة الاستخدام المحترف (Professional CSS UI/UX Designer Skill)

هذه المهارة تمنح الوكيل المعرفي قدرات كبير مصممي المنتجات الرقمية (Principal Product & UI/UX Designer) وهندسة CSS المتقدمة لإنتاج واجهات راقية ذات موثوقية عالية وتأثير بصري فخم.

---

## 1. المبادئ الجوهرية للتصميم الاحترافي (Core Design Philosophy)

1. **التصميم الموجه بالوظيفة (Function-Driven Aesthetic):**
   - الجمال في واجهات الويب مرتبط مباشرة بالوضوح وسهولة الاستخدام.
   - البنية البصرية يجب أن تخدم المستخدم لإتمام مهامه بأقل عدد من النقرات وبأعلى درجات الراحة النفسية.

2. **الوقار والأناقة (Premium & Authoritative Look):**
   - تجنب الواجهات الباهتة أو البدائية. كل بكسل، تباعد، وظل يجب أن يكون مدروساً بعناية.
   - استخدام تدرجات إضاءة ناعمة (Ambient Gradients) وأسطح محكمة بدلاً من الخلفيات الصماء أو الإطارات المزعجة.

3. **الطباعة العربية الفاخرة (Arabic Typography & RTL Mastery):**
   - اعتماد خطوط عربية حديثة وعالية الجودة:
     - **العناوين والأرقام البارزة:** `Cairo` أو `IBM Plex Sans Arabic` بأوزان (600, 700) مع تفعيل الأرقام الجدولية `font-variant-numeric: tabular-nums`.
     - **نصوص الواجهة، الأزرار، والفقرات:** `Tajawal` أو `Readex Pro` بأوزان (400, 500) لضمان أقصى درجات المقروئية.
   - مراعاة الاتجاه من اليمين لليسار (RTL) في حركة العناصر، الأيقونات الاتجاهية، ومرونة التمدد.

## 2. نظام التوكنات وهندسة CSS (CSS Architecture & Design Tokens)

  --primary-hover: hsl(158, 64%, 14%);
  --primary-foreground: hsl(0, 0%, 100%);

  /* اللمسات الذهبية الوقورة للبيئات القانونية والمهنية */

  --gold-subtle: hsl(43, 90%, 96%);

  /* الأسطح والحدود */
  --surface-base: hsl(0, 0%, 100%);

  --surface-card: hsl(0, 0%, 100%);
  --border-subtle: hsl(150, 10%, 90%);

  --text-primary: hsl(200, 24%, 12%);
  --text-secondary: hsl(200, 12%, 40%);
  --text-muted: hsl(200, 10%, 60%);

  /* الظلال الناعمة متعددة الطبقات */

## 3. التجاوب المتقن للأجهزة المتعددة (Multi-Device Responsiveness)

| مقاس الشاشة | تصنيف الجهاز | نمط التوزيع والتخطيط |
| :--- | :--- | :--- |
| `< 640px` | **الجوال (Mobile)** | بطاقات عمودية، شريط ملاحة سفلي مدمج بـ `safe-area-inset-bottom`، مساحة لمس $\ge 48\text{px}$، وانعدام التمرير الأفقي. |
| `641px - 1024px` | **التابلت (Tablet)** | شبكة بطاقات 2×2، شريط أدوات علوي مرن، وجداول بيانات ذات تمرير أفقي محمي للبيانات المعقدة. |
| `> 1024px` | **سطح المكتب (Desktop)** | شريط جانبي ثابت، شبكة رباعية للمؤشرات، أقصى عرض للحاوية `1400px` مع هوامش مريحة للعين. |

## 4. قائمة المحظورات البصرية (Forbidden Cliché Design Tropes)

- ❌ **ممنوع الأرجواني في الخلفيات الداكنة (No Purple on Dark):** تجنب النصوص البنفسجية في الواجهات المظلمة.
- ❌ **ممنوع الخطوط الضخمة غير الموزونة (No Untracked Large Headings):** ضبط تباعد الأحرف والأسطر دائماً.
- ❌ **ممنوع الإطارات المتداخلة المفرطة (No Over-Nested Cards):** عدم وضع كارت داخل كارت داخل كارت.
- ❌ **ممنوع خلفيات الشبكات الشبكية المشتتة (No Distracting Grid Backgrounds).**
- ❌ **ممنوع استخدام أزرار بدون حالات التفاعل الكاملة (Hover, Active, Focus-Visible, Disabled, Loading).**

---

## 5. معايير الميكرو أنيميشن والتفاعل الحركي (Micro-Interactions)

- **انتقالات ناعمة:** استخدام `transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1);`.
- **تأثيرات الأزرار والبطاقات:** رفع طفيف عند التحويم `transform: translateY(-2px);` مع زيادة عمق الظل `box-shadow`.
- **هياكل التحميل (Skeleton Loaders):** اعتماد وميض ناعم خفيف يمنح المستخدم انطباعاً بسرعة النظام.

---

## 6. خطوات التنفيذ عند استدعاء هذه المهارة

1. **تحليل الهيكل البصري الحالي:** مراجعة التباعد، نسب التباين (Contrast Ratios)، والخطوط في الصفحة المستهدفة.
2. **تطبيق التوكنات والأنماط الموحدة:** الاعتماد على متغيرات CSS الموحدة في `src/styles.css` أو مكونات التصميم.
3. **الفحص والتأكيد الميداني:** التحقق عبر محاكاة شاشات الجوال والتابلت والكمبيوتر والتأكد من صفر تجاوز أفقي.
