# تفعيل وظهور «المحامية بيان» المساعد القانوني الذكي لكل قضية

## الهدف
إظهار وتفعيل زر ومساعد «المحامية بيان» في صفحة تفاصيل كل قضية (`/_authenticated/cases/$id`)، لتكون المستشارة القانونية والباحثة الرقمية الذكية المخصصة لوقائع ومستندات كل قضية والأنظمة السعودية.

## ما سيحدث للمستخدم
- عند الدخول على أي قضية من صفحة القضايا (`/cases`)، يظهر زر بارز في الشريط العلوي بجانب زر الطباعة والتعديل: **`[ ✨ المحامية بيان ]`** بتدرج لوني كحلي وذهبي مميز.
- عند النقر على الزر، تنزلق نافذة محادثة جانبية فاخرة (`BayanCopilotDrawer`) مع رسالة ترحيبية تستعرض وقائع القضية المحددة.
- تظهر أزرار استفسارات سريعة مقترحة بنقرة واحدة:
  1. *«لخص وقائع هذه الدعوى والموقف الإجرائي الحالي»*
  2. *«ما هي الدفوع الشكلية والموضوعية الموصى بتقديمها؟»*
  3. *«احسب المهل النظامية المتبقية ومواعيد الاعتراض»*
  4. *«حلل أسانيد الإثبات ومستندات القضية وفق نظام الإثبات»*
- استجابة فورية باللغة القانونية السعودية الرصينة مع أسانيد ومواد الأنظمة المرجعية وأزرار نسخ الردود.

## التنفيذ التقني

### 1. مكون الواجهة (Bayan Copilot Drawer)
- `src/components/cases/bayan-copilot-drawer.tsx`: نافذة استشارة جانبية تفاعلية مع حارس عزل المحادثات ومحددات الأمان.

### 2. الربط في صفحة تفاصيل القضية
- `src/routes/_authenticated/cases.$id.tsx`:
  - إضافة زر `[ ✨ المحامية بيان ]` في شريط الإجراءات العلوي.
  - ربط وتضمين مكون `<BayanCopilotDrawer />` مع معرّف القضية والمكتب.

### 3. محرك الذكاء والـ API الخادمي
- `src/lib/ai/bayan-copilot.server.ts`: محرك بناء سياق القضية مع درع حجب وتعمية البيانات الشخصية (Saudi PII Redaction) وتوليد الاستشارات القانونية.
- `src/routes/api/ai/bayan-chat.ts`: مسار استرجاع وحفظ استشارات المحامية بيان.

### 4. قاعدة البيانات
- `supabase/migrations/20260817220000_case_ai_bayan_copilot.sql`: جداول `case_ai_conversations` و `case_ai_messages` وسياسات RLS للعزل التام.
