# خطة: إزالة زر الدخول برابط لمرة واحدة (Magic Link) من صفحة تسجيل الدخول

## الهدف
إزالة خيار "الدخول برابط لمرة واحدة عبر البريد" من `src/routes/login.tsx`، مع الاحتفاق الكامل بتسجيل الدخول عبر البريد/كلمة المرور أو عبر Google.

## التغييرات المطلوبة
1. في `src/routes/login.tsx`:
   - إزالة زر Magic Link (النص الحالي: "الدخول برابط لمرة واحدة عبر البريد").
   - إزالة دالة `requestMagicLink` المحلية إذا لم تُستخدم في مكان آخر بالملف.
   - إزالة استيراد `sendMagicLink` إذا أصبح غير مستخدم.
   - الاحتفاظ بزر "إعادة إرسال رابط التأكيد" الخاص بحالات البريد غير المؤكد (`needsConfirmation`).
   - الاحتفاظ بحالة `actionBusy` لأنها لا تزال تخدم زر إعادة إرسال التأكيد.
2. التحقق من عدم وجود استخدامات أخرى لـ `sendMagicLink` داخل `src/routes/login.tsx` قبل حذف الاستيراد.
3. تشغيل Type Check و ESLint للتأكد من عدم وجود أخطاء أو استيرادات عالقة.
4. مراجعة بصرية سريعة عبر المعاينة للتأكد من:
   - بقاء تخطيط البطاقة متوازناً في RTL.
   - عمل زر "دخول" وزر "المتابعة عبر Google".
   - عدم ظهور أي خطأ في وحدة التحكم.

## ما لن يتغير
- منطق تسجيل الدخول بالبريد/كلمة المرور.
- منطق تسجيل الدخول عبر Google.
- رابط "نسيت كلمة المرور؟".
- رابط "إنشاء حساب".
- مكوّن `AuthShell` وسلوك `variant="login"`.
- أي مسارات أو منطق خلفي (Supabase / Auth).

## ملاحظة
هذا تعديل واجهة ضيق في ملف واحد فقط؛ لا يتطلب تغييرات في قاعدة البيانات أو المصادقة أو المسارات الأخرى.
