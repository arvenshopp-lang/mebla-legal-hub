# معاينات المشاركة الاجتماعية — كسر الكاش وإعادة التحديث

## المصدر الوحيد

كل روابط الأيقونات وصورة المعاينة تُشتق من `src/config/brand-assets.ts`:

- `BRAND_ASSET_VERSION` — مفتاح الإصدار الملحق بكل رابط أصل (`?v=...`).
- `OG_IMAGE` — صورة المشاركة الرسمية 1200×630 (`/og-mehlalex-v3.jpg`).
- `BRAND_ICON_HREFS` — روابط الأيقونات والمانيفست المستخدمة في رأس الصفحة.
- `socialPreviewMeta()` — الواجهة الوحيدة لوسوم `og:image` و`twitter:image` في الصفحات العامة.

ممنوع كتابة رابط صورة أو أيقونة يدوياً داخل أي Route.

## عند تحديث الشعار أو صورة المعاينة

1. استبدل ملف الأصل في `public/` (مع الحفاظ على الاسم كي لا تنكسر معاينات محفوظة).
2. غيّر قيمة `BRAND_ASSET_VERSION` (مثال: `2026-09-v4`).
3. شغّل `bun run brand:check` للتأكد أن كل الصفحات العامة تُرجع نفس الروابط الجديدة.
4. انشر، ثم أعد سحب المعاينة حسب الجدول أدناه.

## إعادة سحب المعاينة لكل منصة

| المنصة | الطريقة | ملاحظة |
| --- | --- | --- |
| واتساب | Facebook Sharing Debugger → «Scrape Again» | واتساب يقرأ كاش فيسبوك؛ لا يوجد مسح مستقل له |
| فيسبوك | Facebook Sharing Debugger | يُنفَّذ لكل رابط على حدة |
| X (تويتر) | لا يوجد Debugger عام حالياً | تغيّر رابط الصورة بمفتاح `?v=` يجعل البطاقة الجديدة تظهر في أول تغريدة جديدة |
| لينكدإن | LinkedIn Post Inspector | «Inspect» يُعيد السحب |
| تلغرام | مراسلة `@WebpageBot` بالرابط | يُبطل كاش المعاينة فوراً |

## توقّعات زمنية

- بعد إعادة السحب اليدوي: المعاينة الجديدة فورية.
- بدون إعادة سحب: تتحدّث المنصات على جدولها الخاص (قد يصل إلى أسابيع في فيسبوك/واتساب).
- الأيقونات في المتصفحات: تظهر الجديدة بعد أول تحميل بعد تغيير الإصدار؛ التطبيقات المثبَّتة على الجوال قد تحتاج إعادة تثبيت لتحديث أيقونة الشاشة الرئيسية.
